
# Stayzy

Stayzy is a modern accommodation discovery and booking platform designed to simplify finding, exploring, and booking stays.

## Project

A full-stack accommodation platform with separate experiences for customers, property owners, and administrators.

## Development Team

- Member 1 — Frontend, UI/UX, customer experience, mobile interface
- Kesavan — Backend, database, APIs, business logic, integrations

## Development Branches

- `main` — Stable code
- `develop` — Integrated development
- `feature/*` — Individual feature development

Under active development.
